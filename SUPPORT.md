# Getting help

Open an issue in the repository you use. Questions are as welcome as bug
reports: if something was hard to work out, the documentation has a gap.

The project list is on the [machine-made website](https://machine-made.github.io)
and the [organisation page](https://github.com/machine-made).

## What makes an issue easy to answer

In order of use: the exact commands you ran, the full error message, your OS
and language version, and the package version. A short script that reproduces
the problem helps most.

## Response times

Expect days, not hours. Nothing is ignored.

## Other things

- **Security problems**: do not use the public tracker. See
  [SECURITY.md](SECURITY.md).
- **Conduct**: see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- **Contributing a fix**: see `CONTRIBUTING.md` in the repository.
- **Citing the software**: see `CITATION.cff` or the Citation section of the
  README.
